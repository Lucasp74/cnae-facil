# Códigos de versões antigas da CNAE

Para abrir ou alterar um CNPJ hoje vale só a **CNAE-Subclasses 2.3** (1.332 códigos). Se um CNPJ antigo tem um código que não aparece em [../cnae/](../cnae/), ele vem de uma versão anterior.

| Versão | Subclasses | Observação |
|---|---|---|
| CNAE-Subclasses 2.3 | 1.332 | Vigente |
| CNAE-Subclasses 2.2 | 1.329 | Na 2.3 saíram 6 códigos e entraram 9 |
| CNAE-Subclasses 2.1 | 1.318 | |
| CNAE-Subclasses 2.0 | 1.301 | |
| CNAE-Fiscal 1.1 | 1.182 | Estrutura diferente (17 seções); não compare código por código |
| CNAE-Fiscal 1.0 | | Estrutura diferente (17 seções) |

Fonte: IBGE/CONCLA, tabela de correspondência CNAE-Subclasses 2.2 x 2.3. Para versões mais antigas, use as tabelas de correspondência em [concla.ibge.gov.br](https://concla.ibge.gov.br/classificacoes/download-concla.html).

Se o seu CNPJ tem um código extinto, peça ao contador a atualização para o código correspondente na 2.3. Isso é feito por alteração cadastral na Junta Comercial ou no cartório, conforme o tipo de empresa.
