# Nome do tipo de negócio

Uma ou duas frases dizendo para quem esta solução serve.

## Quando usar

- O que o negócio faz.
- O que não está coberto aqui (e qual solução usar no lugar).

## CNAE principal

**0000-0/00 Descrição oficial.** Por que é este código, citando a nota "Inclui" da classe quando ajudar.

## CNAEs secundários comuns

| Código | Descrição | Inclua se |
|---|---|---|
| 0000-0/00 | | |

## Enquadramento que paga menos

| Situação | Regime | Por quê |
|---|---|---|
| | MEI / Simples, Anexo X / ... | |

## Cuidados

- Códigos parecidos que não servem e por quê.
- Licenças e registros obrigatórios.

## Fontes

- Arquivo da divisão em `cnae/`.
- Artigo da lei ou anexo da Resolução CGSN 140/2018 de cada regra citada.
